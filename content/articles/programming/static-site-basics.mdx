A static site can be generated from content checked into a repository. Markdown tables are supported:

| Concern | Example |
| --- | --- |
| Content | MDX files |
| Hosting | GitHub Pages |

Inline math such as $a^2 + b^2 = c^2$ and display math are supported:

$$E = mc^2$$

Code blocks are syntax highlighted at build time:

```python
def mean(values: list[float]) -> float:
    return sum(values) / len(values)
```
